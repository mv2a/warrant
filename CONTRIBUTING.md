# Contributing

Warrant is an early draft. The most useful contributions right now are:

- **Critique of the specification.** Where would this break for your team? What would stop you from trusting a warrant? Start a thread in [Discussions](https://github.com/mv2a/warrant/discussions), or open an issue for a concrete proposal.
- **Trials.** Try it on a small real project, and report what the ledger told you and what it missed.
- **Check adapters.** Checks backed by proof tools (Lean, Dafny, Verus), property-based testing, or scenarios evaluated by language models.

For code changes, follow [AGENTS.md](AGENTS.md). It applies to people as much as to agents: standard library only, tests passing, and SPEC.md updated with any change to a format or a rule.
